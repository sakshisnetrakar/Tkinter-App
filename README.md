# Tkinter Local GUI Demo

A simple Python Tkinter desktop application. It opens a native Windows window, so it must be run locally rather than in a browser or headless cloud terminal.

## Run

```cmd
cd "C:\Users\Sakshi S Netrakar\Desktop\Tkinter Local GUI Demo"
python app.py
```

If Python is installed with Tkinter support, a window appears. Enter a name and choose **Show message**.

## Requirements

No third-party Python packages are required. Tkinter is included with standard Windows Python installations.
